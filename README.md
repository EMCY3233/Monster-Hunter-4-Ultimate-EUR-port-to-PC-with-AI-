# Monster Hunter 4 Ultimate EUR — Port to PC with AI

Proyecto de investigación y desarrollo para llevar Monster Hunter 4 Ultimate, edición europea, a PC con ayuda de herramientas de inteligencia artificial.

## Objetivo

Investigar la viabilidad de una adaptación a PC, desarrollar las herramientas necesarias y documentar cada avance con pruebas reproducibles. Este README describe el objetivo del proyecto; no declara que exista un port jugable.

## Organización

- `README.md`: presentación y pautas de colaboración.
- `CHANGELOG.md`: historial de cambios incorporados al repositorio.
- La documentación y las herramientas se añadirán progresivamente, con su procedencia y requisitos de uso.

## Colaboración

El propietario autoriza a los chats del grupo REA PC MH4U + Others a trabajar con este repositorio. Coordinar tareas para evitar cambios simultáneos sobre los mismos archivos. Utilizar ramas y pull requests para cambios de desarrollo y documentar su validación.

Distinguir entre propuestas, análisis estático, pruebas controladas y resultados comprobados en ejecución. Conservar la procedencia de herramientas y referencias, respetando sus licencias. Registrar en el changelog lo que se incorpore realmente al repositorio.

## Archivos del juego

No incorporar ROM, claves, recursos del juego ni otros archivos privados. Las herramientas que los necesiten deberán indicar cómo utilizar una copia local aportada por el usuario.
