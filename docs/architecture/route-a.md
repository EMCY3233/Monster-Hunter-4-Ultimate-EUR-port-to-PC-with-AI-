# Route A and boundaries

The selected research route is MH4UltimateDC for candidate recompilation,
REA/Ghidra for analysis and Azahar for integration. 3dsrecomp/Zakuro is an
alternative after a specific blocker is demonstrated. This repository's initial
tooling validates supplied local profiles; it implements none of those runtimes.

Work proceeds from verified EUR inputs to bounded real-function analysis,
recompilation, differential CPU/memory checks, and only then initialization and
menu integration. Synthetic infrastructure tests cannot satisfy those milestones.
EUR and USA addresses require independent evidence; shared addresses are not
semantic equivalence. Reconcile proposed regional contracts before implementation.

Future mods, patches, content extensions, LAN/online PC networking, possible
cross-platform support, manual saves and presentation/control improvements remain
requirements. Their interfaces should follow demonstrated runtime boundaries;
they do not justify placeholder implementations before recompilation is viable.

No external code is copied in this scaffold. Importing implementations requires
an explicit pinned-commit license and attribution review. A project-wide license
is intentionally left to the repository owner.
